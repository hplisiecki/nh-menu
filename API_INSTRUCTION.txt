Connect to the Nowe Horyzonty festival API using GET https://www.nowehoryzonty.pl/open-api/program. Expect UTF-8 JSON. Validate version before processing; the current version is 2.1. Read program sections from sekcje and films/events from tytuly. Each title may contain cinema screenings in seanse and an online availability window in online. Parse dataCzas, od, and do as dd-MM-yyyy HH:mm in the festival’s local timezone (Europe/Warsaw). Treat all fields except core identifiers as optional, because empty fields are omitted. Refresh no more often than approximately every five minutes and retain the last valid response if a request fails. Do not scrape the HTML site.
